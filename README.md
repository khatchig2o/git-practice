# C Programming Practice

A collection of C programming exercises and small projects created while learning programming fundamentals and preparing for the 42 Piscine.

## Projects

### 1. Hello World
My first steps with C, exploring basic program structure and output using `printf()`.

### 2. Guessing Game
A simple number guessing game. Practice with user input, conditions, loops, and basic program logic.

### 3. Contact Management
A command-line contact management program featuring:
- List contacts
- Add new contacts
- Search contacts by name
- Delete contacts
- Basic input validation

Concepts practiced: structures, arrays, pointers, functions, loops, and string handling.

### 4. Pointers Practice
Exercises focused on understanding pointers and memory addresses in C.

## Requirements

- GCC compiler
- Linux environment or WSL

## Compilation and Execution

Navigate to the project directory and compile the source file.

Example:

```bash
cd hello_world
gcc -Wall -Wextra -Werror hello.c -o hello
./hello
```

For the contact management project:

```bash
cd contact_management
gcc -Wall -Wextra -Werror main.c -o main
./main
```

The same compilation process applies to the other projects, using their respective source filenames.
